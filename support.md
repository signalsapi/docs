# Support

Email **mykola@signalsapi.com**. Include the block below, filled in — it's the fastest way to get
a useful answer on the first reply.

```text
Account email:
Project name or ID:
Search name:
Persona name (if relevant):
Connected people-data provider (if relevant):
What you expected to happen:
What actually happened (include the exact error or status code, if any):
```

For legal, privacy, or data requests, use the address on the [Privacy Policy](/privacy-policy/) or
[Terms of Service](/tos/) instead.
